# 🤖 AI Resume Analyzer & Job Suggestor

## 📌 About the Project

AI Resume Analyzer & Job Suggestor is a beginner-friendly web development project designed to demonstrate how a resume analysis interface can help users explore their skills and suitable career opportunities.

## ✨ Features

* 📄 Resume upload interface for PDF and DOC/DOCX files
* 📊 Sample resume match score display
* 💡 Skills display section
* 💼 Suggested job roles with sample match percentages
* 🎨 Attractive gradient design
* 📱 Responsive layout for different screen sizes

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 🚀 How to Run

1. Download or clone this repository.
2. Open the `index.html` file in your web browser.
3. Select a resume file.
4. Click **Analyze Resume** to test the upload interaction.

## ⚠️ Current Limitations

This is a front-end prototype. Resume parsing, genuine AI analysis, dynamic skill extraction, and live job recommendations are not implemented yet. The displayed score, skills, and job matches are sample data.

## 🎯 Project Objective

To build a foundation for a future AI-powered system that analyzes resumes and suggests suitable job opportunities.
